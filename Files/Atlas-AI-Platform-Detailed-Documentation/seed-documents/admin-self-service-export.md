# Self-Service Export Policy

## Active Account Export

Active accounts may export their own usage reports from the admin console. This self-service export does not include audit logs.

Suspended accounts are outside the scope of this document. If a question asks about suspended accounts or audit logs, use the suspension policy instead.

## Citation Rule

Cite this document only for active-account usage report exports.
